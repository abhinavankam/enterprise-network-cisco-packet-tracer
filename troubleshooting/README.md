This folder contains documented troubleshooting scenarios encountered during the network implementation.

## Incident Reports

| Incident | Issue | Status |
|----------|-------|--------|
| Incident-01 | DHCP Failure - PC cannot obtain IP address | Resolved |

Each incident report follows the structured NOC troubleshooting methodology:
- **Incident Description**
- **Symptoms Observed**
- **Investigation Steps**
- **Commands Used**
- **Root Cause**
- **Resolution**
- **Validation**
